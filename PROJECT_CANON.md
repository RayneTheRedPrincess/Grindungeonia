# Project Canon

- Grindungeonia is an original Game Boy Advance-first loot/buildcraft action RPG.
- North star: explore what a deep Path-of-Exile-class ARPG could feel like if it had been designed specifically for GBA hardware. This is a mechanical/genre target only; copyrighted names, lore, characters, art, exact skill/passive layouts, items, monsters and areas are not copied.
- Core play fantasy: enter dangerous areas -> kill enemy packs -> collect randomized loot -> improve or reshape the build -> kill harder content faster -> defeat bosses/Guardians -> unlock deeper difficulty.
- Combat must be immediate and readable on a D-pad at 240x160. PC mouse controls are not imitated when native handheld controls can do better.
- Buildcraft is a primary pillar, not a side system. Architecture should grow toward attributes, a large interconnected passive network, equipment bases/item levels, generated affixes, rarity tiers, sockets/links, active/support skills, physical/elemental damage, crit, attack/cast speed, armor/evasion/energy-like defenses, resistances, ailments, leech/regen, conversion, penetration, damage over time, minions and crafting.
- Those systems are introduced incrementally. Prefer reusable tags/modifiers and data-driven interactions over one-off hardcoding.
- Loot must be readable on a 240x160 screen. Density, particles, enemies and item labels are budgeted for clarity and GBA limits rather than blindly matching modern-PC quantities.
- Difficulty Tier N+1 unlocks for a character only after that character defeats Tier N's Guardian. Level alone never unlocks tiers.
- Tier journey: enter -> finite floors/areas -> possible mid-boss -> more content -> Guardian -> Tier Cleared.
- After a Guardian dies, RETURN ends safely; DESCEND enters optional endless scaling content. The clear remains permanent even if the character later dies in descent.
- Track Highest Tier Cleared and Deepest Descent separately.
- Priority is a finished playable V1. Build small playable milestones that prove the ARPG loop before expanding breadth.
- GitHub is canonical source. The external development kit/toolchain is not vendored into this repository.

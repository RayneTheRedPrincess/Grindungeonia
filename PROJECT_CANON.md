# Project Canon

- Grindungeonia is an original Game Boy Advance top-down action RPG.
- Presentation target: fast, readable dungeon combat. Mechanical references may inform design, but copyrighted assets/content are not copied.
- Progression is built to grow through reusable tags/modifiers rather than one-off interactions.
- Difficulty Tier N+1 unlocks for a character only after that character defeats Tier N's Guardian. Level alone never unlocks tiers.
- Tier journey: enter -> finite floors -> possible mid-boss -> more floors -> Guardian -> Tier Cleared.
- After a Guardian dies, RETURN ends safely; DESCEND enters optional endless scaling content. The clear remains permanent even if the character later dies in descent.
- Track Highest Tier Cleared and Deepest Descent separately.
- Priority is a finished playable V1. Build small playable milestones before expanding systems.
- GitHub is canonical source. The external development kit/toolchain is not vendored into this repository.

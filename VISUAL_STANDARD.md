# Visual Standard

- Judge sprites, animation, attacks and VFX in the running 240x160 game, not from source PNGs alone.
- Iteration loop: edit -> build -> emulate -> capture native frames/sequences -> inspect -> revise.
- Combat readability takes priority over decorative detail.
- A future Visual Lab must expose animation frames, directions, weapons, enemies, VFX, hit/hurt boxes, collision and crowded OAM conditions.

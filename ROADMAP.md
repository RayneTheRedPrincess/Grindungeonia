# Roadmap

## G0.0 Project Bootstrap
Verified build, emulator, input and native frame-capture pipeline. First Grindungeonia ROM boots to a development screen.

## G0 Combat Room
One player, one weapon, one enemy, movement, attack, dodge, HP/damage/death/restart, representative dungeon room, and basic combat VFX.

## Later
Grow combat readability, content, progression, tier journey, itemization and character-building incrementally. Do not front-load the full long-term ARPG system list.
